# relaybox v0.1.0

## Highlights

- initial public release
- stable NATS event ID extraction from headers and payloads
- canonical JSON hashing fallback for stable duplicate detection
- idempotent NATS handler with pluggable claim store
- in-memory store for tests, examples, and simple consumers
- CI, contributor docs, and example consumer included

## Notes

This release is intentionally small and focused. It does not yet include the broader outbox and delayed-queue extraction planned for later versions.
